# SQL — Fundamentos e Consultas

Base de conhecimento SQL organizada por nível de aprendizado, com foco em análise de dados e engenharia de pipelines.

## Objetivos

- Consolidar os comandos e funções utilizados nos projetos de análise.
- Servir como referência rápida para consultas e boas práticas.
- Evoluir do básico ao avançado com exemplos práticos aplicados.

## Ferramentas

- **PostgreSQL** — Banco relacional principal
- **Terminal (psql)** — Criação e administração de bancos
- **Jupyter Notebook** — Análise exploratória e execução de consultas via SQLAlchemy

## Nível de conhecimento

Consultas com agrupamentos, filtros complexos, subconsultas, CTEs e funções de janela, aplicadas em projetos de análise de vendas, marketing e retenção de clientes.

---

> Os exemplos são extraídos de projetos reais e estão disponíveis na pasta `queries/` de cada análise.
