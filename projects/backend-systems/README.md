# Backend Systems

Projetos práticos voltados para o desenvolvimento de soluções back-end, arquitetura de sistemas e rotinas de infraestrutura.

## Escopo de Prática

Este repositório é dedicado à construção de projetos para exercitar a rotina técnica de desenvolvimento, suporte L2 e QA, aplicando:

- Construção de APIs e rotinas de código em Python
- Modelagem relacional e manipulação de dados no PostgreSQL
- Conteinerização de ambientes de desenvolvimento com Podman / Docker
- Validação de requisições HTTP e rotas via Postman
- Análise de logs, diagnóstico de erros e escrita de casos de teste
