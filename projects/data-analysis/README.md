# Data Analysis

Análises de dados com foco em negócio, utilizando SQL, Python e ferramentas de visualização.

**Cada projeto segue um fluxo estruturado:**

1. **Extração** — Dados carregados em PostgreSQL via Python (pandas + SQLAlchemy).
2. **Processamento** — Consultas SQL modulares organizadas em scripts, executadas via Jupyter Notebook.
3. **Qualidade** — Testes automatizados para validação de dados (`quality_checks.py`).
4. **Visualização** — Dashboards interativos com Metabase e Excel.
5. **Automação** — Pipelines reprodutíveis com CI/CD via GitHub Actions.

## Objetivos

- Praticar o pipeline completo de análise e engenharia de dados.
- Responder perguntas reais de negócio com base em dados.
- Gerar recomendações claras e acionáveis.
- Evoluir para pipelines automatizados e orquestração com ferramentas de DataOps.

---

> Os projetos estão organizados por tema e incluem desde análises exploratórias até pipelines com CI/CD e containers.
