# Data Analysis

Análises de dados com foco em negócio, usando SQL, Python e ferramentas de visualização.

Cada projeto segue um fluxo:

1. Extração dos dados com SQL (PostgreSQL)
2. Análise exploratória com Python (Jupyter Notebook)
3. Visualização com Metabase ou Excel
4. Dashboard final com KPIs e recomendações

## Objetivos

- Praticar o pipeline completo de análise
- Responder perguntas reais de negócio
- Gerar recomendações baseadas em dados
- Evoluir para pipelines automatizados com Python
